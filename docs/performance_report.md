## 4. 关键结论

### 4.1 数据质量 > 策略复杂度

```
语义 Chunking:              Recall 0.07 → 0.584   (🔺+734%)
MMR 多样性重排:               Recall 0.584 → 0.584  (🔻无改善)
Cross-Encoder Reranker:      Recall 0.584 → 0.584  (🔻无改善)
查询改写:                    Recall 0.584 → 0.584  (🔻无改善)
Auto-merge 不当使用:         Recall 0.584 → 0.075  (🔻暴跌)
```

- **最有效的改动**: 语义 Chunking（53 行代码，Recall +734%）
- **无效的改动**: 查询改写、Reranker、MMR（在此场景下）
- **有害的改动**: Auto-merge 导致的 context 重复

### 4.2 最优策略组合

```python
# 正式环境推荐配置
use_hybrid=True         # BM25 + 向量并行检索（RRF 融合）
use_reranker=False      # Cross-Encoder 本地模型，增益微小
use_rewriting=False     # 查询改写确认无效，已全局禁用
strategy="balanced"     # L1 摘要 + L2 上下文 + L3 精确内容
top_k=5                 # 返回 Top-5 上下文
```

**理由**:
- **hybrid** 在 Recall（0.8738）和 Precision（0.9233）之间取得最佳平衡
- 不加 reranker 避免模型加载依赖，同时 Recall 几乎无损失（-0.2%）
- Balanced 策略确保了上下文既有全局背景又有精确内容

### 4.3 系统的通用性

> 虽然测评基于深度学习文档，但 P0-3 的分词优化采用 PMI 算法**自动从文档中提取领域复合词**，不依赖任何预设词典。无论用户上传的是医学、法律、工程还是金融文档，系统都能自适应学习其领域术语。因此结论适用于任意领域的 RAG 场景。
